# YUREXIS RP — Support Center

Русскоязычный Telegram-бот техподдержки с красивым меню, заявками и личной панелью операторов. **Супергруппа не нужна:** пользователь и каждый оператор общаются с ботом в личных сообщениях.

## Что умеет бот

- Стартовое меню в стиле YUREXIS RP: создать обращение, мои обращения, информация о проекте.
- Заявки с уникальными номерами и статусами «Открыта / Закрыта».
- Уведомления владельцу и операторам в личные сообщения.
- Ответ пользователю через кнопку «Ответить»: после нажатия сообщения оператора пересылаются пользователю, пока оператор не завершит режим ответа.
- Текст, фотографии и документы пересылаются через Telegram Bot API.
- Владелец может выдавать и отзывать права командами `/grant TELEGRAM_ID` и `/revoke TELEGRAM_ID`.
- Панель персонала: открытые заявки, статистика, управление персоналом.
- Supabase хранит заявки, операторов, сессии ответов и журнал событий.
- Vercel serverless webhook.

## 1. Создайте Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather), выполните `/newbot` и скопируйте токен.
2. Откройте созданного бота и нажмите **Start**.
3. Узнайте свой числовой Telegram ID через команду `/id` у бота.

## 2. Создайте базу Supabase

1. Создайте проект на [Supabase](https://supabase.com/).
2. Откройте **SQL Editor** и выполните весь файл `supabase.sql`.
3. В настройках API проекта скопируйте Project URL и секретный `service_role` key.
4. Не добавляйте настоящий ключ в GitHub и не вставляйте его в клиентский код.

## 3. Загрузите проект на GitHub

Загрузите все файлы проекта в новый репозиторий. Файл `.env.example` содержит только примеры, реальные секреты в него не вставляйте.

## 4. Разверните на Vercel

1. Импортируйте репозиторий на [Vercel](https://vercel.com/).
2. В **Project Settings → Environment Variables** добавьте:
   - `BOT_TOKEN` — токен от BotFather
   - `OWNER_ID` — ваш Telegram ID
   - `SUPABASE_URL` — URL проекта Supabase
   - `SUPABASE_SERVICE_ROLE_KEY` — секретный ключ Supabase
   - `WEBHOOK_SECRET` — длинная случайная строка (буквы и цифры)
3. Нажмите Deploy и скопируйте домен production deployment, например `https://your-project.vercel.app`.

## 5. Подключите webhook

Откройте в браузере адрес ниже, заменив значения на свои. **Не делитесь ссылкой**, поскольку в ней содержится токен бота:

`https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<YOUR-VERCEL-DOMAIN>/api/webhook&secret_token=<WEBHOOK_SECRET>`

Успешный ответ Telegram содержит `"ok":true` и `"result":true`.

Проверить состояние webhook можно запросом:

`https://api.telegram.org/bot<BOT_TOKEN>/getWebhookInfo`

## 6. Добавление операторов

1. Каждый будущий оператор должен сначала открыть бота и нажать `/start`. Это нужно, потому что Telegram не разрешает боту начинать личный диалог с пользователем, который ещё не запускал бота.
2. Владелец отправляет боту `/grant TELEGRAM_ID`.
3. Оператор получает доступ к панели персонала и уведомления о новых обращениях.
4. Чтобы убрать права, владелец отправляет `/revoke TELEGRAM_ID`.

## Команды

- `/start` — главное меню или панель персонала
- `/help` — инструкция
- `/id` — ваш Telegram ID
- `/grant TELEGRAM_ID` — выдать права (только владелец)
- `/revoke TELEGRAM_ID` — отозвать права (только владелец)
- `/stopreply` — завершить режим ответа

## Важные ограничения

- Супергруппа и темы Telegram не используются.
- Перед публичным запуском проверьте создание заявок, уведомления, ответы и закрытие заявок на тестовых аккаунтах.
- В `ticket_messages` сохраняются метаданные событий, а не текст содержимого сообщений.
- Владелец и операторы должны хотя бы один раз нажать `/start` у бота, иначе бот не сможет писать им первым.
- Для production рекомендуется добавить антиспам, ограничения частоты, правила хранения данных и резервные копии Supabase.
